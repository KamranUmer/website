## 📌 Overview

My personal portfolio website, built with React components and styled with Sass (SCSS compiled to `dist/css`).

## 🚀 Getting Started

```bash
git clone https://github.com/KamranUmer/website.git
cd website
npm install
# open dist/index.html, or run your bundler of choice
```

## 📁 Project Structure

```
website/
├── index.jsx       # React entry point
├── scss/main.scss  # styles
└── dist/           # built HTML and CSS
```
